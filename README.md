# 🧭 تطبيق مسار | Masar App

**مسار (Masar)** هو تطبيق ويب تفاعلي مبسط (MVP) تم بناؤه باستخدام لغة بايثون ومكتبة **Streamlit**. يهدف التطبيق لمساعدة أولياء الأمور في توجيه أطفالهم نحو قنوات يوتيوب تعليمية وتثقيفية هادفة وموثوقة بناءً على الفئات العمرية واهتماماتهم الشخصية، لحمايتهم من تضييع الوقت في المحتوى غير المفيد وتطوير مهاراتهم للمستقبل.

---

## 🎨 مميزات التطبيق (Features)
*   **تصميم عصري متجاوب (Mobile-Friendly)**: واجهة مستخدم حديثة بأسلوب الزجاج الضبابي (Glassmorphism) تتناسب تماماً مع الهواتف المحمولة والشاشات المختلفة.
*   **خطوط عربية أنيقة**: استخدام خط **Cairo** لتقديم تجربة قراءة مريحة واحترافية.
*   **ميزة المفضلة التفاعلية**: إمكانية حفظ القنوات المقترحة في قائمة المفضلة للرجوع إليها لاحقاً بسهولة.
*   **بيانات حقيقية موثقة**: يحتوي التطبيق على قنوات يوتيوب حقيقية وموثقة بعناية تغطي العلوم، التكنولوجيا، البرمجة، الفنون، الأخلاق، وتطوير الذات لمختلف الفئات العمرية (من 4 إلى 16 سنة).
*   **شعار ذكي مخصص**: تصميم شعار رسمي فريد للتطبيق مدمج بذكاء في الترويسة.

---

## 🛠️ التكنولوجيا المستخدمة (Tech Stack)
*   **لغة البرمجة**: Python
*   **واجهة المستخدم والمنطق**: Streamlit 1.58.0+
*   **تنسيق الواجهة**: HTML & CSS مخصص لدعم اتجاه النصوص من اليمين إلى اليسار (RTL).

## 🚀 طريقة التشغيل محلياً (How to Run Locally)

### 1. المتطلبات الأساسية
تأكد من تثبيت لغة بايثون (Python 3.8 أو أعلى) على جهازك.

### 2. تحميل المشروع والانتقال للمجلد
```bash
git clone https://github.com/ranaawaad/masra_kids.git
cd masra_kids
```

### 3. إنشاء بيئة عمل افتراضية وتفعيلها
*   **على نظام ويندوز (Windows)**:
    ```bash
    python -m venv venv
    venv\Scripts\activate
    ```
*   **على أنظمة ماك/لينكس (Mac/Linux)**:
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

### 4. تثبيت المكتبات المطلوبة
```bash
pip install -r requirements.txt
```

### 5. تشغيل التطبيق
```bash
streamlit run app.py
```

سيفتح المتصفح تلقائياً ويعرض لك واجهة التطبيق التفاعلية على الرابط المحلي: `http://localhost:8501`.

## 📂 هيكلية المشروع (Project Structure)
*   `app.py`: ملف التطبيق الرئيسي الذي يدير الواجهة البرمجية والتفاعلية والتنسيقات.
*   `channels_data.py`: قاعدة البيانات المصغرة التي تحتوي على تفاصيل القنوات والروابط.
*   `requirements.txt`: ملف المكتبات والتبعيات البرمجية اللازمة لتشغيل التطبيق.
*   `masar_logo.png`: شعار التطبيق البصري.
*   `README.md`: هذا الملف التعريفي بالمشروع.
